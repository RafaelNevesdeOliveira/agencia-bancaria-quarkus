# Agência Bancária em Quarkus — início do aluno

Projeto Java 17 gerado do zero pelo plugin Maven Quarkus 3.40.1, com
`rest-jackson` e `hibernate-validator`. Ainda não há entidade, service,
repository ou endpoint bancário: este é o ponto de partida do desafio do
Dia 1. Leia `README-BRANCHES.md` para a progressão das aulas.

Comando validado para gerar este scaffold:

```sh
mvn io.quarkus.platform:quarkus-maven-plugin:3.40.1:create -DprojectGroupId=br.edu.fiap -DprojectArtifactId=agencia-bancaria-quarkus -DprojectVersion=1.0.0-SNAPSHOT -Dextensions=rest-jackson,hibernate-validator -DnoCode
```
